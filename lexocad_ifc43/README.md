# merced.lxz in IFC 4.3 (preliminary)

`merced_ifc43_preliminary.ifc` is the Lexocad model merced.lxz converted to IFC 4.3 (IFC4X3_ADD2): 427 elements. The four cars in merced.lxz are left out.

The 289 elements in bright magenta have no confirmed IFC 4.3 class yet. Each carries the property set MER99_Conversion, which states the open question.

It is made from merced.lxz with Lexocad 31's IFC 4 export and IfcOpenShell, not from MERCED_SR99_solid.ifc.
